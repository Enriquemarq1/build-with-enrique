# Contributing

Useful additions include clearer instructions, corrected links, tested setup notes and small examples you made yourself.

For a correction, describe what you tried, what happened and the file or passage you would change. State the tool version if it affects the result. A proposed improvement and a tested workflow should be clearly distinguished.

Submit only material you have permission to share publicly. Do not upload credentials, personal recordings, private campaign briefs, client files, paid asset libraries or private workspace exports. If an example needs an external asset, link to its legitimate source and explain the requirements.

Keep guides simple, specific and easy to follow. Explain a tool through the job it does. Avoid unsupported promises about guaranteed quality, earnings, virality or identical AI outputs.
