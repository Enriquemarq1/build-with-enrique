# Start here — Build with Enrique

This library helps you put AI to work in content creation. You can read the guides for free and copy the templates into your own projects.

## 1. Choose what you want to do

Browse the [resource index](RESOURCES.md), or start with [Teach AI your editing style](resources/ai-video-editing/README.md).

If you arrived from a video, use the collection linked in its description. That page brings the guide and relevant files together.

## 2. Check what you need

Each collection explains the starting materials, required tools and what is included. The resources are free to access; some tools may require their own account or subscription.

For AI editing, start with one short recording you can use, an editing reference, and access to the tools in the setup checklist.

## 3. Get the files and try it

You can read and copy a document directly on GitHub. To download the library, return to the repository home page and select **Code → Download ZIP**. Extract it, then copy the template you need into a separate working folder.

Fill in your own brief and preferences. If you are using an AI agent, tell it which starting file to read. Naming a tool in a document does not install or connect it.

Follow the guide on one small project, review what you get, and adjust. Keep your recordings and work in your own folder.

## What the labels mean

- **Guide:** an explanation or sequence you can follow.
- **Prompt:** a starting request to adapt to your situation.
- **Template:** a file or folder you fill in and reuse.
- **Skill:** reusable agent instructions, with a stated installation method when one is provided.
- **Example:** a result that shows what a particular process produced.

The current editing collection contains guides, prompts and templates. It does not yet provide an installable editing skill or a verified end-to-end starter run.
