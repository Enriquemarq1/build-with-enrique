# Editing workflow

1. Read the brief and selected style. Resolve the actual source and reference paths.
2. Inspect the recording, dimensions, sound and available transcript/timing data.
3. Check that the selected editing and generation tools are available. Report missing dependencies before promising an output.
4. Plan what helps the viewer: where to keep the speaker, where an insert clarifies the point, caption treatment and sound intent.
5. Produce a representative short preview with the selected tools. Preserve source media and meaningful speech.
6. Watch/listen to the preview, collect specific feedback and apply corrections.
7. Save reusable style guidance separately from shot-specific changes.
8. Export the requested format, verify playback and retain editable sources and selected assets with the project.

This file explains responsibilities. The chosen editor's own documentation and skills govern implementation. Do not invent caption timings, tool access or successful review.
