# Teach AI your editing style

Your AI editor needs two things: a way to do the job, and a clear idea of what you want the result to look and feel like.

The **editing workflow** handles the recording, edit plan, assembly, preview and export. The **style guide** captures your creative direction: pacing, captions, visuals, movement and sound. An agent skill can load that guidance when you ask for the style.

## 1. Set up your editor

Start with one short recording and [this workspace template](../../templates/editor-workspace/START-HERE.md). Add a brief, a style reference and the assets you want the agent to use. Work through the [setup checklist](setup.md), then produce one preview you can watch and hear.

The first finish line is a playable preview—not a folder full of instructions.

## 2. Shape your style

Show examples and explain what you like about each one. One may guide the captions; another may guide the animation. Decide what should stay consistent and where the editor can use judgment.

Review the preview and give [specific feedback](feedback.md). When creating animated B-roll, settle the starting image before asking for motion. Use the [image-to-motion worksheet](image-to-motion.md) to describe the action and what should remain consistent.

## 3. Save what works

Ask the agent to save useful recurring decisions in the style guide. Keep corrections that apply only to one shot in that video's feedback file.

Then try another clip. Review whether the instructions carry the style across. A saved skill helps reuse decisions; it does not guarantee identical or perfect results.

## What this collection provides

Guides, prompts and a file structure you can adapt. It does not install an agent, a rendering engine or a generation service. Choose and connect those tools before expecting an export. No tool is automatically connected simply because you name it in a prompt.
