# Set up your AI editor

## Prepare one small project

- Copy the [workspace template](../../templates/editor-workspace/START-HERE.md) into a working folder.
- Add a short recording you own or have permission to use.
- Fill in the video brief: audience, message, format, selected style and output.
- Add one or two references. Explain what the agent should learn from each.
- Supply any selected font or sound files with their usage rights.

## Check the tools

Ask the agent to inspect what is actually available: the editing/rendering tool, transcript and word-timing route, image/video generation connection and local asset paths.

This workflow can use HyperFrames for composition/rendering and Higgsfield for generated motion. Their installation, account access and available features need to be checked on your machine; this template does not bundle either tool. Keep API keys in the chosen tool's secure configuration, not in shared project documents.

## Start with this request

```text
Read START-HERE.md, editor/workflow.md, styles/my-style/style.md,
and projects/first-video/brief.md in this working folder.
Inspect the recording and references I supplied.
Check which required tools and assets are available; explain what is missing.
Tell me what editing style you understand from the examples.
Once the needed tools are ready, make one short preview.
Save the editable source and preview in this project and tell me what to review.
Do not treat an instruction file as proof that a tool is installed or connected.
```

## Verify the first result

Watch the whole preview and listen to it. Check the spoken meaning, caption wording and timing, framing, readability, motion and sound. Find the exported video and the editable source. Record specific corrections before expanding to a full video.

This checklist is documentation. A completed run on your machine supplies the execution evidence.
